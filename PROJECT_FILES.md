## Key Features Implementation

### Task Management (src/App.jsx)
- Add tasks: `addTask(taskData)`
- Update tasks: `updateTask(taskId, data)`
- Delete tasks: `deleteTask(taskId)`
- Move tasks: `moveTask(taskId, newStatus)`

### Persistence (src/App.jsx)
- Save to localStorage (STORAGE_KEY)
- Load on mount
- Auto-save on task changes

### Drag & Drop (src/components/Column.jsx)
- Drag start: Save dragged task
- Drag over: Accept drop
- Drop: Move task to new column

### Search & Filter (src/App.jsx)
- Filter by title/description
- Filter by priority level
- Combined filtering support

### Theming (src/App.jsx & index.css)
- Light theme: Light backgrounds, dark text
- Dark theme: Dark backgrounds, light text
- CSS custom properties for easy switching
- Persists to localStorage

## How to Use This Project

## Further Customization

### Add Custom Columns
Edit `App.jsx` line with `const COLUMNS = ['Todo', 'In Progress', 'Done']`

### Change Colors
Edit color values in:
- `src/components/TaskCard.jsx` (priority colors)
- `src/components/TaskForm.jsx` (color picker)
- `src/index.css` (CSS custom properties)

### Add Features
Create new components in `src/components/` and import in `App.jsx`

### Improve Performance
- Run `npm run build` and analyze bundle
- Use React DevTools Profiler
- Monitor Lighthouse scores
